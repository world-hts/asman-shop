# Asman Shop V2.0.0 — Storefront visual redesign

## What changed
- Rebranded customer and admin defaults from the generic placeholder name to Asman Shop.
- Introduced a responsive sky-blue/turquoise visual system for the header, hero, search, categories, product cards, detail pages, footer and mobile navigation.
- Improved spacing, hierarchy, focus states, reduced-motion behavior and mobile safe-area spacing.
- Updated PWA display name and cache namespace.
- Preserved the single-store architecture, TK/RU/EN localization, search/category filtering, stock display, product details, phone contact, Supabase integration, admin functionality and PWA foundation.
- Kept the demo catalogue clearly identified as demo content in the setup guide.

## Verification status
- Source and project structure updated in this archive.
- Automated project audit scripts are included and should be run on the Mac after `pnpm install`.
- A fresh dependency install, production build, browser/mobile visual check and live Supabase admin CRUD test have **not** been run against this V2 archive in this environment. Do not treat those as PASS until the Mac test results confirm them.
